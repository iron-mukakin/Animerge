論文「Margin-Aware Preference Optimization for Aligning Diffusion Models without Reference」に基づき、sd-scriptsの改修およびanima (nvidia cosmos)のADDifT学習へのMaPOモード追加の実装に必要な数式、メカニズム、実装上のポイントを以下に要約する。1. 目的関数（Loss Function）の定義MaPOの全体損失関数 $\mathcal{L}_{\text{MaPO}}$ は、通常の拡散モデルの平均二乗誤差（MSE）損失 $\mathcal{L}_{\text{MSE}}$ と、参照モデル（Reference Model）を必要としないマージン認識型正則化項 $\mathcal{L}_{\text{Margin}}$ の組み合わせで構成される 。
プロンプトを $c$、好ましい（Chosen）画像を $x_0^w$、好ましくない（Rejected）画像を $x_0^l$ としたとき、数式は以下の通り定義される 。  $$\mathcal{L}_{\text{MaPO}}(c, x_0^w, x_0^l) := \mathcal{L}_{\text{MSE}}(c, x_0^w) + \frac{1}{\beta}\mathcal{L}_{\text{Margin}}(c, x_0^w, x_0^l)$$  ① スコアベースの教師あり微調整（SFT）項好ましいペア $(c, x_0^w)$ の尤度を最大化するため、通常のDDPM（あるいは各拡散プロセスに応じた）MSE損失を適用する 。
  $$\mathcal{L}_{\text{MSE}}(c, x_0^w) := \mathbb{E}_{\epsilon, t} \left[ \| [cite_start]\epsilon - \epsilon_\theta(x_t, c, t) \|^2 \right]$$※ preference learningと同時にSFTを行うことで、モデル分布をデータ分布に逐次適合させ、分布の乖離を防ぐ効果がある 。  ② マージン正則化（Margin Regularization）項好ましい画像と好ましくない画像のMSE損失の差（マージン）を最適化する。DPOのように参照モデルの対数尤度比を使用せず、現在のモデル自身の損失のみで計算を行う 。
  $$\mathcal{L}_{\text{Margin}}(c, x_0^w, x_0^l) := -\log \sigma \left( \phi_\beta(\mathcal{L}_{\text{MSE}}(c, x_0^w)) - \phi_\beta(\mathcal{L}_{\text{MSE}}(c, x_0^l)) \right)$$  ここで、 $\sigma$ はシグモイド関数、 $\phi_\beta$ は以下の有界リンク関数（Bounded Link Function）である 。  2. 有界リンク関数（Link Function）DPOのインプリシット・リワードのように報酬値が無限に発散して過学習を起こすのを防ぐため、出力を $(0, 1)$ に制限する以下の関数を使用する 。
  $$\phi_\beta(\mathcal{L}) := \frac{1}{1 + \beta (\exp(\mathcal{L}) - 1)}$$  $\beta$ の役割: スコア関数の温度（Temperature）を制御するハイパーパラメータ 。$\beta$ が大きくなるほど、より小さな尤度マージンで損失が最小化されるようになる 。  $\frac{1}{\beta}$ による重み付け: $\nabla_\theta \mathcal{L}_{\text{Margin}}$ の勾配が $\beta$ に比例するため、その影響を相殺するために全体の損失関数において $\frac{1}{\beta}$ を乗算してバランスをとっている 。  3. 実装における重要な仕様とメリット参照モデル（Reference Model）の排除:
DPOとは異なり、推論・フリーズされた固定の参照モデルのネットワークをメモリ上に保持したり、フォワードパスを通したりする必要がない 。そのため、実装側ではターゲットのモデル（訓練モデル）の勾配計算および損失計算のみを追跡すればよい。  計算資源と効率:
参照モデルが不要になることでピークGPUメモリが削減され（論文中ではSDXLベースで約17.5%削減）、同一環境下で最大4倍のバッチサイズを適用可能となる 。  データセットの構造:
データ入力としては、同一プロンプトに対して (prompt, chosen_image, rejected_image) のペア（トリプレット）を供給する仕組みが必要となる 。既存のDiffusion-DPOデータローダーを流用可能。  4. sd-scriptsへの組み込み方針データローダーの調整:chosen と rejected の画像、および対応する prompt を同時にバッチとして返すデータローダー、またはDiffusion-DPO用のコンポーネントを利用する。フォワードパスの変更:同一ステップ・同一ノイズ（またはそれぞれの画像に対応する拡散パス）を用いて、chosen に対する $\mathcal{L}_{\text{MSE}}(x_0^w)$ と rejected に対する $\mathcal{L}_{\text{MSE}}(x_0^l)$ を計算する 。  損失計算ロジックの追加:数式 (11) の $\phi_\beta$ を関数として実装する 。計算時の数値的安定性（安定したexp計算）に注意する。  数式 (10) の $\mathcal{L}_{\text{Margin}}$ を算出し、最終的なTotal Lossとして $\mathcal{L}_{\text{MSE}}(x_0^w) + \frac{1}{\beta} \mathcal{L}_{\text{Margin}}$ を返すように損失計算部を記述する 。
