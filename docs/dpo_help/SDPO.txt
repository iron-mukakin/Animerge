nvidia cosmosのADDifT学習にDiffusion-SDPO（Safeguarded Direct Preference Optimization）を追加するにあたり、実装に必要なアルゴリズムおよび数式の要約は以下の通りです。1. 目的と基本的なアルゴリズム従来のDiffusion-DPOは「勝者（Winner）」の予測誤差を下げ、「敗者（Loser）」の予測誤差を上げるように最適化を行いますが、これが過剰になると勝者側の生成品質まで悪化（Lossが上昇）させる問題があります 。
Diffusion-SDPOは、勝者側の損失（$\mathcal{L}^w$）を増加させない（$\Delta\mathcal{L}^w \le 0$） という安全条件を満たすように、敗者側の勾配にアダプティブなスケーリング係数 $\lambda_{safe}$ を乗算して更新を行います 。  2. 主要な数式と計算プロセス① 各ブランチの残差損失（Step 3）拡散モデルの予測ノイズ $\hat{\epsilon}_{\theta}$ と、フリーズされた参照モデル（Reference Model）の予測ノイズ $\hat{\epsilon}_{ref}$、およびグラウンドトゥルースのノイズ $\epsilon$ を用いて、勝者（$w$）と敗者（$l$）それぞれの損失を計算します 。
  $$\mathcal{L}^{w} = \frac{1}{2}||\hat{\epsilon}_{\theta}^{w} - \epsilon||_{2}^{2} - \frac{1}{2}||\hat{\epsilon}_{ref}^{w} - \epsilon||_{2}^{2}$$  $$\mathcal{L}^{l} = \frac{1}{2}||\hat{\epsilon}_{\theta}^{l} - \epsilon||_{2}^{2} - \frac{1}{2}||\hat{\epsilon}_{ref}^{l} - \epsilon||_{2}^{2}$$  ② 出力空間勾配（Output-Space Gradients）の取得高次元なパラメータ空間での勾配計算を避けるため、モデルの出力空間（出力アクティベーション）における勾配 $g^w, g^l$ を用いてプロキシ計算を行います 。デノイザーの予測出力に対する勾配は、損失関数の定義より以下のように定義されます 。
  $$g^w = \nabla_{o}\mathcal{L}^w, \quad g^l = \nabla_{o}\mathcal{L}^l$$  ③ 安全スケーリング係数 $\lambda_{safe}$ の計算（Step 4）出力空間勾配の内積 $g^{w\top}g^l$ が正の場合（敗者の勾配が勝者の損失を悪化させる方向にある場合）、以下の数式で制限をかけます 。
  $$\lambda_{safe} = \frac{(1-\mu)||g^w||_2^2}{g^{w\top}g^l}$$  $\mu \in [0, 1]$ は安全マージンを調整するハイパーパラメータ（slack factor）です 。  クリッピング処理：安定性の向上と intrinsically safe な状態（$g^{w\top}g^l \le 0$）への対応のため、$\lambda_{safe}$ は必ず $[0, 1]$ の範囲にクリップします 。（※ $g^{w\top}g^l \le 0$ のときは $\lambda_{safe} = 1$ とする ）。  ④ 敗者ブランチの勾配スケーリング（Step 5）敗者側の損失計算において、勾配を停止させたコピー $\mathcal{L}_{detach}^{l}$ を利用して、$\lambda_{safe}$ による勾配スケーリングを適用します 。
  $$\mathcal{L}_{scaled}^{l} = \mathcal{L}_{detach}^{l} + \lambda_{safe}(\mathcal{L}^{l} - \mathcal{L}_{detach}^{l})$$  ⑤ 最終的なDPO損失関数の構築（Step 6）通常のBradley-Terryモデルに基づくシグモイド関数を用いた損失関数に、上記でスケーリングされた敗者損失を組み込みます 。
  $$\mathcal{L}_{DPO} = -\log \sigma(-\beta(\mathcal{L}^{w} - \mathcal{L}_{scaled}^{l}))$$この $\mathcal{L}_{DPO}$ を用いてモデルパラメータ $\theta$ を逆伝播・更新します 。  3. 実装上の留意点・コードへの組み込み方既存DPOパイプラインへのプラグイン化：Diffusion-SDPOはモデルの構造に依存しない（model-agnostic）ため、sd-script内の既存のDPO損失計算部分を微修正するだけで導入可能です 。  計算オーバーヘッドの最小化：パラメータ空間のヤコビアンを追跡せず、すでに計算されている出力空間の残差（予測ノイズとターゲットの差分など）のベクトルから $g^w, g^l$ を得るため、追加の計算コストやメモリ消費は極めて軽微です 。  ハイパーパラメータ $\mu$ の設定基準：論文の実験設定では、UNetやDiTなどのモデル特性に応じて $\mu = 0.2 \sim 0.9$ の範囲が使用されています 。初期値としては、標準的な設定である 0.6 前後からテストすることが推奨されます 。
